# Places-Agent 产品重构计划

## Context

**2026-08-31：** places-agent + where2play **MVP-10 重构方案已确定**（§12 轻骨架 + Travor UI mock 定稿）。功能总表见 **批次 11**；where2play 消费端 = Feature **37** `plan-46`；agent = Feature **43–45、47**。
