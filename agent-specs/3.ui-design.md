# places-agent — admin UI design

Operator management web on **`places.agent-mate.ai`**. Pixel and interaction contract for Features 14–19. Stories: [`1.agent-stories.md`](./1.agent-stories.md). ACs: [`2.agent-ac.md`](./2.agent-ac.md). Clickable mock-ups: [`ui-mockup/`](./ui-mockup/). App Router map: [`5.agent-design.md`](./5.agent-design.md).

This document covers **app** chrome only. Consumer what2eat / where2play screens are out of scope.

---

## 1. Subject

| | |
| --- | --- |
| **Product** | Operator app for the place gateway identified as `places-agent` |
| **Audience** | Ethan and invited admins |
| **Job of the UI** | Sign in, invite admins, issue and revoke **caller API keys**, read how to call HTTP and MCP |

Callers never use this UI. Map-vendor keys (AMAP / Google / Tripadvisor) never appear here.

---

## 2. Direction

**性冷淡**, same family as [kb.agent-mate.ai](https://kb.agent-mate.ai): off-white field, black ink, hairline rules, zero radius, leftover space.

Personality sits in **one** place: `agent-logo.png` (hand-drawn blobs on `--bg` `#fafafa`) as the mark and the browser tab icon. Everything else stays quiet.

| Do | Do not |
| --- | --- |
| Hairline dividers, uppercase mono labels, black rectangle buttons | Shadows, gradients as decoration, border-radius, color status pills |
| Weight and underline for state (active nav, active locale) | Icons in the left nav |
| Show a caller secret once (create / regenerate) | “View secret again” from the list |
| Four locale codes `EN CN HK TW` | A two-way 中文 / EN switcher (HK and TW would collapse) |

Motion: one short rise on public/auth first paint (`12px`, `700ms`). Respect `prefers-reduced-motion`. No ambient animation on signed-in tables.

## 4. Shells

Four shells. Locale switcher is on every shell (Feature 19).

```text
PUBLIC HOME                         AUTH (login / reset / set password)
┌─────────────────────────────┐     ┌─────────────────────────────┐
│                    EN CN HK TW│     │                    EN CN HK TW│
│                               │     │  [logo] places.agent-mate.ai │
│  [logo] places.agent-mate.ai  │     │  notice (register closed)    │
│  tagline                      │     │  title                       │
│  ─────────────────────────    │     │  fields                      │
│  instructions link            │     │  [Sign in]  Reset password   │
│  [Sign in]                    │     │  Back to home                │
│                    copyright  │     │                    copyright  │
└─────────────────────────────┘     └─────────────────────────────┘

GUIDE (public)                      APP (signed-in)
┌─────────────────────────────┐     ┌─────────────────────────────┐
│ [logo] host   Back  EN CN…  │     │ [logo] host  Hello, {name}   │
│ CONNECT                     │     │ instructions   EN CN HK TW   │
│ Agent instructions          │     ├────────┬────────────────────┤
│ toc · body · diagrams       │     │ Keys   │ EYEBROW            │
│                    copyright│     │ Admins │ Title      [Issue] │
└─────────────────────────────┘     │ Sign out│ table / form      │
                                    └────────┴────────────────────┘
```

| Shell | Routes (conceptual) | Chrome |
| --- | --- | --- |
| Public home | `/` | Centered column `max-width: 26rem`, left-aligned inside. No sidebar. |
| Auth | `/login`, `/reset-password`, `/set-password` | Same column. Register notice on login only. |
| Guide | `/instructions` | Thin header, content `max-width: 42rem`. Same URL signed-in or not; signed-in visitors keep the **app** header + left nav and drop the public “Back to home”. |
| App | `/admin/api-keys`, `/admin/api-keys/new`, `/admin/api-keys/:id`, `/admin/users` (`/admin` → keys) | Header + `200px` text nav. Default landing after login = **Keys**. |

Unsigned visitors who open an app route go to login (AC: landing shell is not shown).

**Left nav items** (i18n keys, no icons):

1. `admin.nav.keys` → keys list (landing)
2. `admin.nav.admins` → admin users
3. `admin.nav.sign_out` → ends session, returns to home

Active item: ink color, weight 500, `2px` inset bar on the left. Sign out stays mute; it is never “active”.

**Header (app):** mark + hostname (home) · `admin.landing.instructions_link` · `admin.landing.hello` with `{name}` · locale switcher.

**Locale switcher:** four **protocol ids** `EN` `CN` `HK` `TW` (not translated). Active = ink + underline. Persist in the browser for the mock-up; production may use cookie or `Accept-Language` override. `html lang`: `en` / `zh-CN` / `zh-HK` / `zh-TW`.

**Footer:** `admin.footer.copyright` right-aligned. Optional skip control `admin.a11y.skip` top of DOM (visually hidden until focus). On narrow viewports, left nav collapses behind `admin.nav.menu`.

## 5. Components

All user-facing strings are **keys**. Selectors for tests: `data-i18n` and `data-testid`. Do not assert English literals.

| Component | Spec |
| --- | --- |
| **Primary button** | Black fill, white type, 1.5px ink border, radius 0. Label is a verb: Sign in, Issue new key, Save, Invite. |
| **Text link** | Ink, 1px `line-strong` underline; hover underline → ink. Used for instructions, reset, back, row actions. |
| **Text button (danger-quiet)** | Mute type, no fill. Hover → ink. Delete / Revoke / Regenerate sit here, not as red pills. |
| **Field** | Mono uppercase label above; value is a bottom-border input (no box). Focus: bottom border + 2px ink outline offset. Password: eye toggle, `aria-pressed`. |
| **Notice** | `fill` background, 1px `line` border, mute body. Login: `admin.register.disabled_notice`. Errors: `danger` type, key such as `errors.login_failed`. |
| **Table** | No vertical rules. Header row mono uppercase. Row actions are text links in a trailing cell: Edit · Regenerate · Delete. Prefix column is mono. Status `ACTIVE` is ink; other statuses mute. |
| **Secret panel** | Mono secret, copy control `admin.keys.copy`. Warning that the secret will not be shown again. |
| **Dialog** | Sharp rectangle, 1px line, no shadow beyond a 28% ink scrim. Confirm regenerate / delete only. |
| **Code block** | 1.5px `line-strong` border, `#f4f4f4` fill, mono, copy control. Machine id `places-agent` and hostnames stay literal. |
| **Flow diagram** | Hairline boxes. The **Caller API key** node is the only inverted block (black fill, off-white type). |

Keyboard: visible `2px` ink focus rings. Escape closes dialogs. Primary actions are reachable without a pointer.

### 6.3 Reset password — US3

**File:** `03-reset.html` (`?sent=1`)

Email field + `admin.reset.submit`. Success: single `callout-success` with `admin.reset.sent` (includes junk-folder note); form and lead hidden. Failure: keyed error, password unchanged.

**Email layout (Resend):** `12-email-reset.html` — table HTML, 性冷淡 card on `#fafafa`. Must include: logo + hostname, eyebrow, heading, who/why copy, black CTA button, plain-link fallback, ignore-if-not-you line, footer (`admin.mail.*` keys). Invite reuses the same shell: `13-email-invite.html`. Invite CTA links to **`/accept-invite?token=…`**, not set-password. Production sends **HTML + text** (text mirrors link).

### 6.4 Accept invite — US4

### 6.5 Set password — US5 (reset and empty session only)

**File:** `04-set-password.html`

| Variant | Query | Purpose |
| --- | --- | --- |
| Empty hash (signed-in) | (default) | `admin.set_password.lead` — first boot / empty password |
| Reset link | `?token=…` | `admin.set_password.reset_lead` only |
| Saved | `?done=1` | Success callout + **`admin.set_password.sign_in`** button → login |
| Expired token | expired callout | Expired **callout only** (logo + callout + action); no form |
| Mismatch | inline error | `errors.password_mismatch` inline above fields |

Invite onboarding is **not** on this screen — use §6.4 accept-invite.

Callouts use `.callout` / `.callout-error` / `.callout-success` (eyebrow + title + body + optional action). Do not stack conflicting leads with a one-line error.

### 6.6 Agent instructions — `places-agent-admin-instructions`

**Files:** `05-instructions.html` (public header), `11-instructions-app.html` (app shell)

Same body. Must state, in keys:

1. How to call HTTP
2. How to call MCP
3. How to send a **caller API key** (`Authorization: Bearer`)
4. Agent id is the literal **`places-agent`** (never replaced by a translated catalog value)

Suggested section order (this *is* a sequence): Architecture → Get a key → HTTP → MCP.

Diagram: HTTP (app BFF) and MCP (host) join at an inverted **Caller API key** node, then `places-agent`, then map vendors as a mute footnote — vendors are not configurable here.

Entries: home link `admin.home.instructions_link`; signed-in header `admin.landing.instructions_link`.

### 6.7 Keys list (landing) — `places-agent-admin-landing` + `places-agent-admin-api-keys`

**File:** `06-keys.html` (`?empty=1`)

Default screen after login. Eyebrow `admin.keys.eyebrow`, title `admin.keys.title`, lead `admin.keys.lead`, primary `admin.keys.issue`.

| Column key | Content |
| --- | --- |
| `admin.keys.col_name` | Admin-given name |
| `admin.keys.col_prefix` | Public prefix only (mono). Never the full secret. |
| `admin.keys.col_status` | `admin.keys.status_active` |
| `admin.keys.col_issued` | Locale-aware date |

Row actions: `admin.keys.edit` · `admin.keys.regenerate` · `admin.keys.delete`.

Empty: `admin.keys.empty` + control to create.

### 6.8 Create key — API keys US1

**Files:** `07-key-new.html`, `08-key-created.html`

New: name, description, submit generates a secret.

Created: plaintext secret **once**, copy via `admin.keys.copy`, warning `admin.keys.created_warn`. No later “view full secret” on the list (stricter than kb’s Users “View”).

### 6.9 Edit key — US2–US4

**File:** `09-key-edit.html` (`?confirm=regenerate` \| `delete`)

Edit name/description without rotating. Regenerating shows a new secret (same created-secret pattern) and the previous secret stops working. Delete removes the row. Confirm in a sharp dialog.

### 6.10 Admins — users US4

**File:** `10-admins.html`

Eyebrow `admin.users.eyebrow`. Invite by email (Resend). Columns: name, email, status (`ACTIVE` / `PENDING`). Invited admins must set a password before the landing works.

## 7. i18n

Catalogs: `EN` (default), `CN`, `HK`, `TW`. Missing key → `EN` → the key string. Page stays up (Feature 19 US3).

`HK` and `TW` are both Traditional and **must differ in wording** (not OpenCC of `CN`). Protocol ids not translated: `places-agent`, `EN`/`CN`/`HK`/`TW`, `AMAP`, `GOOGLE_MAPS`, `TRIPADVISOR`, `OPEN_METEO`, default username `admin`, default email `me@ethanhuang.com`. Weather **labels** are not protocol ids — they use `weather.wmo.{code}` catalogs (ADR-014).

Locale-sensitive dates on the keys table (e.g. `2026-08-17` may stay ISO in `EN`; `CN`/`HK`/`TW` may use `YYYY年M月D日`).

Mock-ups apply keys through `data-i18n` and `assets/i18n.js` (catalogs inlined so `file://` works).

---

## 8. Copy rules

- Name controls by what the operator does: Issue new key, Copy secret, Regenerate, Delete, Invite admin.
- Empty keys: invite to issue the first key.
- Errors name the failure and the next step (`errors.login_failed`, `errors.password_required`). No apology theater.
- Do not mention map-vendor keys, Portainer, or Quanzil in this UI.

---

## 9. Quality bar (UI)

- Desktop (~1280) and mobile (~390): public/auth column remains readable; app nav becomes a text menu.
- Focus order: skip → locale → main landmarks → primary action.
- Escape closes dialogs.
- Status is not color-only (`ACTIVE` is a word).
- Secrets never go to `localStorage` in production. Mock-up may stash locale only.
- Critical journeys for later E2E: home → login → keys; create key + copy; locale switch EN→HK; closed register notice.
