# Deployment plan — places family

**Consumer:** release-bot (conversational semi-auto release on 野草云3). Operators fill placeholders and follow `0.2.release-bot/knowledge/03-semi-auto-release.md`. This file is the family plan so Step 0 is confirmation, not a second architecture.

**This file lives in** the umbrella repo (`workspace-specs/`). Parent git tracks specs only. Child app repos copy or link stack-specific slices into their own `deployment-plan.md` when Docker/CI exist.

**Spec sources:** [`2.architecture.md`](./2.architecture.md) (especially §10), [`3.tech-specs.md`](./3.tech-specs.md), [`knowledge/handbook.md`](./knowledge/handbook.md) §7, [`../1.places-agent/agent-specs/5.agent-design.md`](../1.places-agent/agent-specs/5.agent-design.md) §2 path map. Binding ADRs: ADR-009, ADR-012, ADR-015–025 (do not duplicate their full text).

**Secrets:** never in this file, git, Portainer screenshots, or chat. Use Portainer env / node `.env` / local key store. Env **names** only. Do not paste caller API key plaintext, `BOOTSTRAP_ADMIN_PASSWORD` values, or vendor keys here.

**AI posture:** places-agent is an **inference-only** Quanzil tool-loop (ADR-004). It is not a training or MLOps platform. Do **not** add Kubeflow, MLflow, a feature store, a model registry, GPU serving, eval-set CI, or canary model routing. Version inference artifacts from day one via env: `PROMPT_ID`, `GLOSSARY_ID`, `CATALOG_PACK`. Rollback = pin `IMAGE_TAG` **and** those ids.

         │                                      │                              │
         │ PLACES_AGENT_API_KEY (server)        │ admin session cookie         │
         └──────────────────────────────────────┼──────────────────────────────┘
                                                ▼
                         Cloudflare DNS (grey cloud until Let's Encrypt OK)
                                                ▼
                         Nginx Proxy Manager on 野草云3 (:80 / :443)
                                                ▼
              ┌─────────────────────────────────┼─────────────────────────────────┐
              ▼                                 ▼                                 ▼
     what2eat-web:3000                 places-agent:3000                  where2play-web:3000
     (stack what2eat)                  (ONE process, ADR-016)             (stack where2play)
                                       server.ts → MCP + Next

                      AMAP              Google Maps REST         Tripadvisor Terra

                         Quanzil (OPENAI_* on this stack)     Open-Meteo     Resend

## 3. Images & CI

Portainer **only pulls**. Never build app images on 野草云3. GitHub Actions builds on GitHub-hosted runners. HK npm Aliyun mirror `https://registry.npmmirror.com` applies to **builds on 野草云3 if any** (ops tools); it is **not** the prod image build path.

| Item | places-agent | what2eat | where2play |
| --- | --- | --- | --- |
| Dockerfile | **Blocker** — land in app repo; `CMD` `node server.ts`; Next standalone copy; Prisma migrate + seed then `exec node server.ts` | Later blocker | Later blocker |
| Workflow | **Blocker** `.github/workflows/ghcr.yml` | Later | Later |
| Registry | `ghcr.io` | `ghcr.io` | `ghcr.io` |
| Proposed image | `…/places.agent-mate.ai/agent` | `…/what2eat.food/web` | `…/where2play.places/web` |
| Tags | `latest` (default branch) + git sha + `v*` | same when CI exists | same when CI exists |
| Node / Next | Next **16.3** standalone; keep patched (ClickFix lesson) | Same family stack when the app exists | Same |
| Playwright in prod image | No | No unless an app spec requires it | No |

If GHCR packages are private, Portainer needs a PAT with `read:packages` (ops key store — not in git).

Portainer often does **not** re-pull `latest` on Update — require **Recreate + Pull**, or pin sha.

## 11. Ops caveats

| Topic | Rule |
| --- | --- |
| `IMAGE_TAG` | Published GHCR tag only (`sha` / `v*` / `latest`). **Never** git branch `main` (release-bot ADR-002). Confirm the tag exists on Packages before Portainer Update. |
| Portainer pull | “Update” often does **not** re-pull `latest`. Recreate + Pull, or pin sha. |
| NPM Save after recreate | After replacing the places-agent container, **Save** the NPM host `places.agent-mate.ai` even without field changes (release-bot ADR-003). Homepage 200 ≠ MCP healthy. |
| Postgres backup | Image rollback does **not** roll back Aliyun `places_agent`. Backup/snapshot that database before schema migrate. |
| Seed | `admin` / `me@ethanhuang.com`. No password in the image. Prod: `BOOTSTRAP_ADMIN_PASSWORD` one-time then unset, or empty hash → `/set-password`. Public register off. |
| Secrets | Rotate anything pasted into chat or screenshots. Never commit `.env`, `.keys`, or caller-key plaintext. |
| GMaps Worker | Not a VPS/Portainer stack. Do not invent a `gmaps-mcp` service on `portainer_network`. |
| Next standalone uploads | Do not serve post-boot `public/` from standalone (release-bot ADR-001). Thin apps: no volume until a spec needs uploads. |
| npm mirror | Aliyun `https://registry.npmmirror.com` for installs **on 野草云3 if any**. Prod images build in GitHub Actions, not on the VPS. |
| ClickFix / HTML inject | Keep Next patched. Probe HTML for `data:text/javascript;base64` before trusting public DNS (release-bot ADR-004). Grey cloud until LE OK. Do not treat homepage 200 as MCP healthy. |
| ChatBox after outage | Clients may need reconnect or app restart after a prolonged agent recreate. |
| LLM rollback | Pin `PROMPT_ID` / `GLOSSARY_ID` / `CATALOG_PACK` with `IMAGE_TAG`. No model registry. |
| Entrypoint | `node server.ts`. Not `next start`. Not a second MCP process. |
| Isolation | Do not restart other stacks to “fix” this one. |
